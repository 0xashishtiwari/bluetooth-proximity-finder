
# Bluetooth Proximity Finder

A command-line tool for discovering nearby Bluetooth Low Energy
(BLE) devices and tracking their signal strength using RSSI.

## Project goals

- Discover nearby BLE devices.
- Display device identifiers and signal strength.
- Calibrate signal strength into approximate proximity bands.
- Track a selected device in real time.
- Smooth noisy RSSI readings.
- Provide optional audio feedback and approximate distance estimates.

## Tech stack

- Python
- Bleak
- Git and GitHub

## Status

Under development.

## Disclaimer

RSSI-based proximity and distance estimates are approximate.
This tool does not provide precise location or direction.
